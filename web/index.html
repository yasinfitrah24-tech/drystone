Drystone predict before you stack

Prototype decision-support tool, not a certified safety device. It estimates the chance that a stack of boxes falls. A person always makes the final call.

Pick a sample photo and where the next box should go. The service reads the box markers with OpenCV, builds a digital twin of the stack, runs a Monte Carlo physics simulation (MuJoCo) and then decides: guide, ask a supervisor, or reject and suggest a safer spot. The rules are fixed code, not a language model.

Zone rules

  • GREEN, P(fall) under 10%: the agent guides the placement.
  • YELLOW, 10–50%: a supervisor approves, uses the suggestion, or rejects.
  • RED, over 50%: the agent rejects and suggests the nearest safe spot. Going on anyway needs an override with a name and a reason. An override is only logged; it never changes the result.
  • P(fall) comes from many simulations with 1 cm position and 2 cm load uncertainty. Near a zone line the agent runs more simulations and, if still unsure, takes the safer zone.

Decisions are computed on AWS Lambda with the same code as the laptop agent (OpenCV 5, MuJoCo). Identical requests are answered from a short-lived cache and marked “cached”. Supervisor choices are written to the server log without your IP address.
